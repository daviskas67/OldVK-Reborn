🚀 OldVK — Revival of the Classic Social Network

 📖 История создания

Оригинальный проект OldVK был замечательной попыткой вернуть классический интерфейс ВКонтакте образца 2012-2014 годов. К сожалению, сервера проекта были атакованы и уничтожены — "очень добрые" люди с помощью DDoS-атак полностью положили сервис.

Но сообщество не сдалось! 🎯

Мы создали альтернативу — полностью рабочую социальную сеть, которая:
- Воспроизводит классический интерфейс ВК 2014 года
- Работает на собственном сервере
- Не зависит от внешних API
- Хранит все данные локально (SQLite)
- Поддерживает весь необходимый функционал



 ⚡ Возможности

 🎨 Дизайн
- Полностью скопирован дизайн ВКонтакте образца 2014 года
- Адаптивный интерфейс (работает на телефонах и компьютерах)
- Возможность кастомизации цветовой схемы профиля

 👥 Пользователи
- Регистрация и авторизация
- Личные страницы с аватарками
- Редактирование профиля (имя, статус, "о себе")
- Поиск других пользователей

 📝 Посты и контент
- Создание постов на стене
- Лайки с уведомлениями
- Комментарии к постам
- Счётчики лайков и комментариев

 💬 Сообщения
- Личные сообщения между пользователями
- Список диалогов
- Уведомления о новых сообщениях
- Отметка о прочтении

 🔔 Уведомления
- Оповещения о лайках
- Оповещения о комментариях
- Счётчик непрочитанных уведомлений

 🔒 Приватность
- Пароли хранятся в зашифрованном виде (SHA-256)
- Токены для авторизации
- Локальная база данных (никто не имеет доступа)



 🛠️ Технологии

| Компонент | Технология |
|--||
| Бэкенд | Python 3 + HTTP сервер |
| База данных | SQLite 3 |
| Фронтенд | HTML5/CSS3/JavaScript (чистый, без фреймворков) |
| Иконки | Оригинальные иконки ВК 2014 |
| Шифрование | SHA-256 для паролей |



 📦 Установка и запуск

 1. Клонирование или скачивание

```
bash
cd ~
git clone https://github.com/daviskas67/oldvk.git
или просто скопируйте файлы в папку


 2. Установка зависимостей

bash
 Для Ubuntu/Debian
sudo apt update
sudo apt install python3 sqlite3

 Для других систем — просто Python 3 (встроенные модули уже есть)


 3. Запуск сервера

bash
cd oldvk/web-vesion
python3 server.py


 4. Доступ к сайту

Откройте в браузере: http://localhost:9090

 5. Публичный доступ (через интернет)

bash
 Запустите туннель в отдельном терминале
ssh -R 80:localhost:9090 localhost.run

 Получите адрес типа: https://xxxxxx.lhr.life
 Поделитесь им с друзьями!
