# 📑 Документация API — OldVK-Reborn

В проекте используется модульная архитектура. Все запросы, начинающиеся с `/api/`, обрабатываются в модуле `api.py`. Обмен данными происходит строго в формате **JSON** с кодировкой `UTF-8`.
